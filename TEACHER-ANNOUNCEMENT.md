# 🌟 ICAN Stellar Apps - Now Accessible Anywhere! 🌍

**Great news, teachers!**

The **ICAN Stellar** suite of applications is now accessible online from anywhere, including from the comfort of your home! No need to be on campus or connected to the school network.

---

## 🌐 Online Access (NEW!) - Access from Anywhere

We're excited to announce that all three Stellar apps are now available via permanent web URLs:

### 📝 **Teacher Report Generator**
**https://icanstellar.ngrok.app**
- Create daily monitoring reports with AI-powered narratives
- Access student data from Notion
- Generate and download report cards

### 📊 **Student Report Viewer**
**https://stellaranalysis.ngrok.app**
- View comprehensive student analytics
- Filter by date range, teacher, or subject
- AI-powered performance analysis and insights

### 🎓 **Report Card Data Generator**
**https://stellarscores.ngrok.app**
- Generate final report cards with tabular score data
- Export data for spreadsheets
- AI-generated final reports (Strengths, Improvements, Recommendations)

---

## 💡 Important: Please Bookmark These URLs!

**These URLs are permanent and will never change.** Add them to your bookmarks for easy access anytime, anywhere!

## 🏫 Local Network Access (Still Available)

If you're on campus and connected to the school network, you can still access the apps using:

**Find the school computer's IP address, then use:**
- Teacher Report Generator: `http://SCHOOL_IP:1441`
- Student Report Viewer: `http://SCHOOL_IP:1442`
- Report Card Data Generator: `http://SCHOOL_IP:1443`

*(Replace `SCHOOL_IP` with the actual IP address provided by IT)*
